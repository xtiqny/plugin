## Privacy Policy

**Last Updated:** August 4, 2026

### Overview

This privacy policy explains how the Holidays plugin ("we", "our", or "us") handles data when you use our Dify plugin. We are committed to protecting your privacy and being transparent about our data practices.

### Data We Collect

The Holidays plugin collects and processes the following information:

1. **User Input Data**
   - Date strings provided by users for holiday queries
   - Example: `2026-07-31`, `2026-7-31`

2. **API Response Data**
   - Holiday information retrieved from timor.tech API
   - Public holiday data including holiday names, dates, and workday adjustments

### How We Use Data

- **Query Processing**: User-provided dates are sent to the timor.tech API to retrieve holiday information
- **Response Delivery**: API responses are processed and returned to the user within the Dify platform
- **No Storage**: We do not store, persist, or retain any user data or query history

### Data Sharing

- **Third-Party API**: User-provided dates are transmitted to timor.tech API (https://timor.tech/api/holiday) for processing
- **No Other Sharing**: We do not share data with any other third parties, advertisers, or data brokers
- **Dify Platform**: All processing occurs within the Dify platform environment

### Data Security

- **Transmission**: All API requests use HTTPS encryption
- **Processing**: Data is processed in real-time and not stored
- **No Personal Data**: We do not collect personally identifiable information (PII)

### User Rights

You have the right to:
- **Access**: Request information about what data is processed
- **Deletion**: Since we do not store data, no deletion is necessary
- **Opt-out**: Discontinue use of the plugin at any time

### Third-Party Services

This plugin relies on the following third-party service:

**timor.tech API**
- **Purpose**: Provides holiday and workday data for China
- **Data Shared**: Date strings only
- **Privacy Policy**: Please refer to timor.tech's privacy policy for their data practices
- **Location**: Data is processed in accordance with their service terms
